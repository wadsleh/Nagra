# 📱 تطبيق نَقْرَة (Nagra) - محفظتك الرقمية الذكية

![Nagra App Banner](https://via.placeholder.com/1200x400/11998e/ffffff?text=Nagra+Digital+Wallet)

**تطبيق "نَقْرَة" (Nagra)** هو منصة دفع إلكترونية ومحفظة رقمية حديثة، تم تصميمها لتسهيل المعاملات المالية اليومية. يوفر التطبيق تجربة مستخدم سلسة وآمنة لإدارة الأموال الرقمية، شحن الأرصدة، وشراء الخدمات الإلكترونية بضغطة زر.

---

## ✨ المميزات الأساسية (Key Features)

- **💰 محفظة رقمية (Nagra Pay):** تغذية الرصيد بأمان عبر التحويلات البنكية (مثل تطبيق بنكك) مع نظام تأكيد وإدارة للرصيد.
- **📱 خدمات الاتصالات:** شحن فوري لرصيد الهواتف لجميع الشبكات المحلية (زين، سوداني، MTN).
- **🎮 الألعاب والاشتراكات:** شراء بطاقات الألعاب (PUBG, Free Fire) وتجديد الاشتراكات الترفيهية (Netflix, Spotify).
- **💳 بطاقات الدفع العالمية:** طلب وإصدار بطاقات افتراضية (Visa & Mastercard) مع عرض شفاف لتفاصيل وشروط الاستخدام.
- **⚙️ لوحة تحكم إدارية (Admin Dashboard):** واجهة قيادة منفصلة للمديرين لمعالجة الطلبات، تأكيد شحن المحافظ، وخصم الأرصدة بنظام التحديث اللحظي (Real-time).
- **🔐 مصادقة آمنة (Authentication):** نظام تسجيل دخول وحماية متطور يدعم البريد الإلكتروني وكلمة المرور، بالإضافة إلى تسجيل الدخول السلس عبر حسابات Google.
- **📜 سجل الطلبات:** تتبع ديناميكي لحالة العمليات (مكتملة، قيد التنفيذ، مرفوضة) لحظة بلحظة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم بناء هذا المشروع بالاعتماد على تقنيات الويب الحديثة وخدمات الاستضافة السحابية:

- **الواجهة الأمامية (Frontend):** - `HTML5` للنمذجة وهيكلة الصفحات.
  - `CSS3` للتنسيق، التصميم المتجاوب (Responsive)، والحركات (Animations).
  - `Vanilla JavaScript (ES6+)` للبرمجة التفاعلية وإدارة حالة التطبيق.
- **الخلفية وقاعدة البيانات (Backend & Database):**
  - **Firebase Authentication:** لإدارة هويات المستخدمين بأمان.
  - **Cloud Firestore:** قاعدة بيانات NoSQL لتخزين الطلبات، بيانات المستخدمين، والأرصدة مع مزامنة لحظية (Real-time Listeners).
  - **Firebase Hosting:** لرفع واستضافة التطبيق (اختياري).
